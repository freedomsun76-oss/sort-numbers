# برنامج الأرقام المشتركة — GitHub Pages + Supabase

**هذه النسخة تحتاج إعداد Supabase مرة واحدة. رفع index.html وحده على GitHub Pages لا يوفّر تخزينًا مشتركًا.**

## الإعداد
1. أنشئ مشروعًا على https://supabase.com (خدمة مستقلة عن GitHub).
2. من لوحة Supabase افتح **SQL Editor** والصق محتوى `setup.sql` بالكامل واضغط Run.
3. من **Authentication → Users** أنشئ مستخدمًا واحدًا للفريق (بريد إلكتروني وكلمة مرور قوية). يمكن للجميع الدخول بنفس هذا الحساب. لا تضع كلمة المرور في ملفات GitHub العامة. يُفضّل تعطيل إنشاء الحسابات العامة.
4. من **Project Settings → API** انسخ **Project URL** و**publishable key** (أو anon key). **ممنوع استخدام service_role أو secret key** في ملف HTML.
5. افتح `index.html` بمحرر نصوص وعدل أول سطرين تحت عبارة "ضع هنا قيم Supabase العامة":
   `const SUPABASE_URL = 'https://YOUR_PROJECT.supabase.co';`
   `const SUPABASE_ANON_KEY = 'YOUR_PUBLIC_KEY';`
6. ارفع `index.html` إلى جذر مستودع GitHub Pages (أو مجلد Pages المعين)، ثم افتح الرابط. سيظهر تسجيل الدخول؛ استخدم حساب الفريق المشترك.

## كيف يعمل؟
- أي زائر يمكنه فتح الصفحة، **لكن قائمة أرقام الهواتف لا تظهر إلا لمن يسجّل دخولًا بحساب الفريق**. هذا لمنع النشر العلني لأرقام أشخاص آخرين.
- الإضافة تتحقق من الأرقام المصرية، وتمنع إدخال الرقم نفسه مجددًا حتى لو سبق نسخه.
- «نسخ 25 رقمًا» يحجز الدفعة بشكل مركزي وذري، فلا يستطيع متصفحان حجز الدفعة نفسها في اللحظة ذاتها.
- «استيراد كأرقام سبق استخدامها» يحفظ الأرشيف ويعتبر الأرقام مستخدمة، وهي خطوة مهمة إذا كان لديك أرقام نسختها باستخدام النسخة القديمة.
- إشعار أخضر يظهر بعد نجاح النسخ. إذا رفض المتصفح الوصول للحافظة، تظهر الدفعة يدويًا وتظل محسوبة مستخدمة.
- القائمة تعرض آخر 100 رقم فقط للتسهيل، بينما تبقى جميع الأرقام محفوظة بقاعدة البيانات.
- حد أقصى 10,000 رقم في استدعاء الخادم الواحد، والواجهة تقسم الإضافة إلى أجزاء من 1,000 رقم.

## مهم جدًا
- بيانات `localStorage` الموجودة في النسخة القديمة **لا تنتقل تلقائيًا** بين المتصفحات. الصق أو استورد الأرشيف القديم باستخدام «استيراد كأرقام سبق استخدامها» قبل بدء نسخ دفعات جديدة.
- لا ترفع ملفات تحتوي على أرقام الهواتف أو كلمة المرور إلى مستودع GitHub عام.
- يحتاج المتصفح إلى اتصال بالإنترنت وتشغيل JavaScript وتحميل مكتبة Supabase الخارجية.
- حساب واحد مشترك يعني أن جميع المصرح لهم بنفس الحساب يمكنهم رؤية أرقام الهاتف، لذلك شارك بيانات الدخول فقط مع فريق مخوّل وبموافقة أصحاب البيانات حيث يلزم.
