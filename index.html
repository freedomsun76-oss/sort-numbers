📋 برنامج الأرقام المشتركة

الموقع مفتوح للزيارة، لكن الأرقام محفوظة ولا تظهر إلا بعد الدخول بحساب الفريق المشترك.

⚙️ إعداد الربط

ضع عنوان Supabase ومفتاح anon / publishable فقط. لا تضع service_role أو أي مفتاح سري هنا.

عشان كل زوار GitHub Pages يستخدموا الربط نفسه، أدخل الإعدادات في ملف HTML داخل المتغيرين SUPABASE_URL و SUPABASE_ANON_KEY قبل الرفع. الحفظ هنا على جهازك فقط.

🔒 دخول الفريق

أنشئ حساب الفريق من Supabase Authentication → Users. لا تنشر كلمة المرور في GitHub.
